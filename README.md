# 🎭 Invitación XV Años - Massiel Berenice

Página web elegante de invitación a los XV años de Massiel Berenice Mejía Ponce.

## ✨ Características

- 📱 Diseño vertical responsivo (9:16)
- 🎨 Tema "Bosque Encantado" elegante
- ✨ Animaciones suaves y refinadas
- 📅 Contador regresivo dinámico
- 🗺️ Integración con Google Maps
- 💬 Integración con WhatsApp
- 📸 Galería de fotos
- 💌 Secciones para lluvia de sobres
- ✅ Formulario de confirmación

## 🎯 Secciones

1. **Portada** - Presentación del evento
2. **Presentación** - Información sobre Massiel
3. **Pergamino** - Invitación formal
4. **Fecha y Hora** - Con contador regresivo
5. **Presentación Especial** - Información adicional
6. **Ubicación** - Lugar del evento
7. **Lluvia de Sobres** - Información de regalos
8. **Confirmación** - RSVP y contacto
9. **Cierre** - Mensaje de cierre
10. **Final** - Página final

## 🚀 Cómo Usar

1. Descarga los archivos
2. Abre `index.html` en tu navegador
3. Personaliza los textos, fechas y fotos según sea necesario

## 🎨 Personalización

### Cambiar Colores
Edita las variables CSS en `styles.css`:
```css
--marfil: #f5f1e8;          /* Color de fondo marfil */
--dorado: #d4af37;          /* Color dorado principal */
--verde-libro: #1a4d2e;     /* Verde del libro */
--bosque-oscuro: #0d2817;   /* Fondo oscuro */
```

### Cambiar Datos
Edita en `index.html`:
- Nombre: Busca "MASSIEL" y cambia
- Fecha: Busca "17 OCTUBRE" y actualiza
- Hora: Busca "3:00 P.M." y modifica
- Ubicación: Busca "Colegio de Abogados"
- WhatsApp: Cambia "+504 9499-0567"

### Agregar Fotos
Reemplaza los placeholders:
```html
<img src="https://via.placeholder.com/300x400" alt="Foto">
```
Con tus URLs de fotos.
